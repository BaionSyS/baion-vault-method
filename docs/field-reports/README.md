# Field reports

These reports are generalized from real operating catches. They are included because a governance method earns credibility by showing where a gate changed an outcome, not merely by describing an ideal workflow.

Each report preserves the sequence:

```text
claim → missing or weak gate → catch → correction → enforcement added
```

- [A correction built from a partial source window](01-partial-source-window.md)
- [A budget-bound null mislabeled as a wall](02-budget-bound-null-not-wall.md)
- [A differential probe corrected attribution](03-differential-attribution.md)
- [An absence claim skipped the authoritative search](04-negative-existence.md)

Names, private paths, unique technical subject matter, counterparties, and nonessential identifiers have been removed. The reports preserve the governance mechanism and correction shape, not the private research substance.

These public summaries are **not independent proof that the underlying incidents occurred or that BVM is effective in every environment**. Their purpose is to make the originating failure modes inspectable enough to challenge, reproduce in a public fixture, or turn into enforcement machinery.
