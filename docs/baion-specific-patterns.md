# BAION-specific patterns

These patterns influenced BVM but are not universal core requirements.

- UTC-first filenames carrying version and artifact type.
- Decorative document stamps or “chrome.”
- Multi-lane AI review rounds with named reviewer roles.
- Rich form cards for operator authorization.
- Deeper private tiering beyond the public reference tree.
- Organization-specific handoff, freeze, and thread-close protocols.
- Local “freshest valid receipt” reconciliation conventions.
- Additional hash ledgers and release packets.

The portable invariant matters more than the local expression. For example, UTC-first naming is one way to improve ordering; the core requirement is unambiguous durable time where chronology controls a transition.
